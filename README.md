# COVID-19 Data Exploration and Tableau Dashboard

## About the Project
In this project, I explored COVID-19 data using SQL Server and created a Tableau dashboard to visualize the results. I analyzed cases, deaths, population, and vaccination data to understand how COVID-19 affected different countries over time.

## Tools Used
- SQL Server
- Tableau Public
- Microsoft Excel

## What I Did
- Analyzed COVID-19 cases and deaths using SQL queries.
- Compared infection rates with population across different countries.
- Analyzed death counts by country and continent.
- Used joins and window functions to analyze vaccination progress.
- Used CTEs, temporary tables, aggregate functions, and views.
- Exported the required query results to Excel and used them in Tableau Public to create visualizations.

## Project Files
- `COVID_19_Data Exploration.sql` – Contains the SQL queries used for data exploration.
- `COVID_19_Tableau_Data_Query_for Dashboard.sql` – Contains the main queries used for the Tableau dashboard.

## What I Learned
Through this project, I practiced SQL data analysis, learned how to calculate useful metrics, and gained experience presenting data through Tableau visualizations.
